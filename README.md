# Tabstage Desktop

Tabs organized in profiles, groups and folders, each profile opening in the browser you choose,
for macOS and Linux.
It is the desktop version of the [Tabstage extension](https://github.com/de-hv/tabstage), for
machines where browser extensions are not allowed.

- **Profiles, groups, folders and tabs:** a profile such as *Work*, *Personal* or a client keeps
  its tabs apart. Inside a profile you are free to organize: groups, folders and tabs can sit
  directly in it; a group holds folders and tabs; a folder holds tabs.
- **A tree in the sidebar:** expand profiles, groups and folders down to each tab. Right-click
  any row (or use its **⋯**) to add what fits inside it, open everything, rename, move or
  delete. The sidebar resizes by dragging its edge and scrolls when the tree is long.
- **Groups as statuses:** a profile opens as a board with one column per group (plus one for
  what sits directly in the profile). Name groups *In progress*, *In TEST*, *Done*, and drag
  a tab or folder to another column to move it along.
- **Icons:** every group, folder and tab has a default icon; pick your own from emoji, an icon
  set, or up to three characters such as a ticket number or a symbol (★, ✓, →).
- **No duplicate tabs:** clicking a tab focuses it when it is already open. This works on
  macOS for Safari and Chromium browsers (Chrome, Edge, Brave, Vivaldi, Arc) through
  AppleScript. Firefox and Linux browsers do not expose their tabs, so a new tab is opened.
- **Drag and drop:** move tabs, folders and groups in the tree, the lists and the board. Every
  menu also has "Move to…" for the keyboard.
- **Quick search:** <kbd>⌥ Option</kbd> <kbd>⇧ Shift</kbd> <kbd>K</kbd> from any app, or
  <kbd>⌘K</kbd> / <kbd>Ctrl K</kbd> in the window.
- **No menu bar icon:** on macOS, closing the window keeps Tabstage running; click its Dock
  icon or use the shortcut to bring it back. On Linux, closing the window quits.
- **One local JSON file:** on first run you choose where it goes (the default location is
  preselected). Cloud folders such as iCloud Drive, Dropbox, OneDrive or Google Drive are not
  allowed. Writes are atomic, and a change made to the file outside the app is never silently
  overwritten.

## Profiles and browsers

A profile is only a way to keep things apart. **Which browser it opens in is chosen in
Settings** and kept in this computer's `config.json`; a profile without one opens in the system
browser. Tabstage does not read or use the browsers' own profiles.

**Data format 3.** Version 0.3 nests groups inside their profile so a profile can also hold
folders and tabs, adds icons, and drops statuses: groups take their place. Files from 0.1 and
0.2 are upgraded automatically; their statuses are removed. Older versions cannot read the new
format.

## Install

```sh
curl -fsSL https://de-hv.github.io/tabstage-desktop/install.sh | sh
```

On Linux this installs the AppImage for your user; add `-s -- --system` to install the `.deb`
or `.rpm` with apt or dnf instead. On macOS you can also use Homebrew:

```sh
brew install --cask de-hv/tap/tabstage
```

Or download a file from the [latest release](https://github.com/de-hv/tabstage-desktop/releases/latest).
Every release has a `SHA256SUMS` file, and the install script checks it.

> The macOS app is not notarized yet. The install script and the Homebrew cask install it
> without the quarantine flag; if you download the `.dmg` yourself, right-click the app and
> choose Open the first time.

## Develop

Requirements: Rust 1.88 or later, Node 22, and on Linux
`libwebkit2gtk-4.1-dev libayatana-appindicator3-dev librsvg2-dev`.

```sh
npm install
npm run dev        # starts Vite and the Tauri window
npm test           # UI tests (Vitest)
cargo test --workspace
sh tests/install_test.sh
```

The project is built test first: every crate and component has its tests next to it, and CI
runs formatting, Clippy with warnings as errors, and all tests on macOS and Ubuntu.

### Layout

```
crates/core      domain model, no IO: profiles, groups, folders, tabs, icons
crates/store     JSON data file: atomic writes, versioned format and upgrades, conflict detection
crates/browsers  find installed browsers, open URLs, focus open tabs
crates/app       application service the UI talks to; tested with a fake system
src-tauri        thin Tauri shell: IPC commands, global shortcut
ui               React + TypeScript interface
site             GitHub Pages site and install.sh
```

`ui/src/test/fixtures/snapshot.json` is generated by Rust and used as mock data by the UI
tests, so the TypeScript types cannot drift from the Rust JSON. Regenerate it with
`UPDATE_UI_FIXTURE=1 cargo test -p tabstage-app ui_fixture`.

## Releases

Commits follow [Conventional Commits](https://www.conventionalcommits.org). release-please
keeps a release PR open on `main`; merging it tags the version, builds the macOS universal
`.dmg` and the Linux `.AppImage`, `.deb` and `.rpm` (x86_64 and arm64), publishes
`SHA256SUMS`, and updates the Homebrew cask in `de-hv/homebrew-tap` when the
`HOMEBREW_TAP_TOKEN` secret is set.
